# Online Payment Fraud Detection

A machine learning project for detecting fraudulent online payment
transactions using Python and Scikit-learn.

## 📌 Project Overview

Online payment fraud is a highly imbalanced classification problem where
fraudulent transactions represent only a small portion of all transactions.

The objective of this project is to build a machine learning model that can
identify potentially fraudulent transactions while focusing on metrics such
as Precision, Recall, F1-score, ROC-AUC and PR-AUC.

---

## 🎯 Objectives

- Understand transaction and fraud patterns through Exploratory Data Analysis
- Engineer meaningful transaction-level features
- Handle the class imbalance problem using class-weighted models
- Train and compare Decision Tree and Random Forest models
- Evaluate model performance using appropriate classification metrics
- Identify important features influencing fraud predictions
- Predict whether a new transaction is fraudulent or legitimate
